# android/

The Bubblewrap TWA project that wraps the PWA into the APK offered on the landing page
(what.md §13, ADR-0015). **Empty until Phase 6** — nothing here is built or released yet.

What it will hold:

- `twa-manifest.json` — `applicationId` `com.konkurleitner.app`, host `app.konkurleitner.com`,
  the same icons and theme colours as the web manifest, portrait, no splash beyond the
  generated one.
- The generated Gradle project, regenerated by Bubblewrap rather than hand-edited.
- `assetlinks` notes: the Digital Asset Links file is served from
  `https://app.konkurleitner.com/.well-known/assetlinks.json` by Caddy, and its SHA-256
  fingerprint must match the signing key, or the TWA shows a browser address bar.

**The keystore is never in git.** It lives in the GitHub secrets `ANDROID_KEYSTORE_B64`,
`ANDROID_KEYSTORE_PASSWORD` and `ANDROID_KEY_ALIAS` (see `.env.example`), and a copy is the
owner's to keep offline: losing it means no user can ever install an update over the old APK.
